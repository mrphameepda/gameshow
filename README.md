**Nền tảng trò chơi giáo dục mục vụ dành cho thiếu nhi, giới trẻ và cộng đoàn Công giáo.**

Tác giả: **Giuse Phạm Duy Ái, SDS**

## 🎯 Các Game Hiện Có

1. **Rung Chuông Vàng PRO** (Đã phát hành)
   - Game đối kháng nhóm 1 - 500 thí sinh.
   - Hỗ trợ máy chiếu (Projector mode).
   - Bộ 260+ câu hỏi (Dễ, Vừa, Khó, Cứu Trợ, Câu Phụ, Đố Vui).
   - Âm thanh và hiệu ứng sinh động.

2. **Ai Là Triệu Phú Đức Tin** (Sắp ra mắt)
3. **Ô Chữ Bí Mật** (Sắp ra mắt)
4. **Đua Thuyền Ga-li-lê** (Sắp ra mắt)

## 🛠 Hướng Dẫn Cài Đặt & Chạy Local

### 1. Yêu cầu hệ thống
- Node.js (phiên bản 18+ trở lên)
- npm hoặc yarn

### 2. Cài đặt

Clone repository về máy:
```bash
git clone https://github.com/mrphameepda/gameshow.git
cd gameshow
```

Cài đặt dependencies:
```bash
npm install
```

### 3. Khởi động môi trường dev
```bash
npm run dev
```
Mở trình duyệt và truy cập vào `http://localhost:5173`.

### 4. Build phiên bản Production
```bash
npm run build
```
Thư mục `dist/` sẽ chứa các file tĩnh sẵn sàng để deploy.
